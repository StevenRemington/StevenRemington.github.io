# Project Context: StevenRemington.github.io

This project is a Jekyll-based technical portfolio and digital workspace for showcasing compiler research, edge AI orchestration, and physical craft.

## Completed Integrations

### 1. Bluesky Crossposting
Automated crossposting via the AT Protocol is active.
- **Workflow:** GitHub Action in `.github/workflows/bluesky-post.yml` triggered by new `_posts/` entries.
- **Status:** Integrated. Requires `BSKY_HANDLE` and `BSKY_PASSWORD` secrets in GitHub.

## Pending Integrations

### 1. Traffic Analytics
- **Decision:** Privacy-focused analytics (GoatCounter/Plausible) preferred over GA4 to match the Appalachian Gothic aesthetic.
- **Status:** Not yet implemented.
